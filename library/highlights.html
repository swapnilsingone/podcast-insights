Highlight reels

The best minute and a half of every conversation.

Auto-cut from the top insight timestamps. Each reel is a self-contained mp4 in videos/<id>/highlight.mp4 — share-friendly, no internet needed.

Generate a reel

Reels aren't auto-built (they're large + need ffmpeg). To generate one for a video, run from the project root: 

brew install yt-dlp ffmpeg   # first time only
python3 scripts/make_highlight.py <video_id>

Options: --top 5 (clip count), --window 18 (seconds per clip), --quality 480 (max video height).
